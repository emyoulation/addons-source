# Anniversaries Gramplet
The **Anniversaries** Gramplet shows (custom or built-in) events that have an anniversary on today’s date, along with the participant, age, and event type. It is a small, stable Gramplet for quick daily review of matching events. 

## Where To Add It
The addon is registered as a general Gramplet with not category restrictions. You can add the Anniversaries Gramplet in the **Dashboard** or gramplet sidebar/bottombar of the **People**, **Families**, **Events**, **Places**, **Sources**, **Citations**, **Repositories**, **Notes** categories. 

## Configuration Access
There are **no additional configuration options** for this addon in the code provided. The gramplet simply builds its own list view and displays anniversaries automatically; it does not define a settings panel or a configurable preferences dialog.

## What It Displays
The list includes the event date, participant, age, and event type. Double-clicking a row opens the event editor for that event, which makes it easy to review or correct the underlying record.

## Notes
The addon scans all events in the database and filters them to those whose month and day match today’s date. It then calculates the age and displays the results in a sortable list.
